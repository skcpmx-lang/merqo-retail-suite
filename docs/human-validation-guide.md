# MERQO Retail Suite v1.0.0 — মানব যাচাই গাইড (Human Validation Guide)

**সংস্করণ:** `v1.0.0-gate.9` (commit `8e9493d`) — **প্রকাশের আগে** যাচাই আবশ্যক।
**যেখানে ইনস্টলার পাবেন:** GitHub Draft Release `v1.0.0-gate.9` → `MERQO Retail Suite-Setup-1.0.0.exe` (89 MB) ও Portable.
**লক্ষ্য:** একজন দোকানের মালিক/ম্যানেজার নিজের Windows 10/11 পিসিতে ইনস্টল করে নিচের ২১টি ধাপ নিজে করে দেখবেন — কোড নয়, বাস্তব ব্যবহার।

> **প্রতিটি ধাপে পাস/ফেল লিখুন।** কোনো ফেল পেলে স্ক্রিনশট + ধাপ নম্বর সহ রিপোর্ট করুন। ফেলের তীব্রতা (Critical/High/Low) উল্লেখ করুন — আমরা ঠিক করে আবার বিল্ড দেব।
>
> **হার্ডওয়্যার যাচাই মিথ্যা দাবি করবেন না।** USB/Bluetooth স্ক্যানার ও 58/80mm থার্মাল প্রিন্টার শুধু তখনই “পাস” বলুন যখন বাস্তব ডিভাইস দিয়ে পরীক্ষা করা হয়েছে।

## পূর্ব-প্রস্তুতি

1. **পিসি:** Windows 10/11 x64। স্ক্রিন রেজোলিউশন 1920×1080 থেকে শুরু করুন; পরে 1366×768 ও 3840×2160 (যদি থাকে) এবং Settings → System → Display → Scale 100%, 125%, 150%, 175% এ আলাদা করে দেখুন।
2. **ডাউনলোড:** GitHub → Releases → `v1.0.0-gate.9` (Draft) → `MERQO Retail Suite-Setup-1.0.0.exe` ডাউনলোড করুন। `SHA256SUMS.txt` এর হ্যাশ মিলিয়ে নিন (ঐচ্ছিক)।
3. **প্রিন্টার/স্ক্যানার প্রস্তুত:** USB স্ক্যানার, Bluetooth স্ক্যানার, 58mm ও 80mm থার্মাল প্রিন্টার, A4 প্রিন্টার (যা আছে) পাশে রাখুন।

## ২১ ধাপ — দোকানের মতো করে

### 1) ইনস্টল
- Setup ডাবল-ক্লিক → লাইসেন্স Accept → Install location নির্বাচন → Desktop/Start Menu shortcut রাখুন → Install।
- **প্রত্যাশা:** NSIS ইনস্টলার ১–২ মিনিটে শেষ, `MERQO Retail Suite.exe` Start Menu-এ আসে।
- **ফেল ধরুন:** ইনস্টলার ক্র্যাশ, shortcut না আসা, uninstaller না তৈরি হওয়া।

### 2) প্রথম চালু
- Start Menu থেকে MERQO চালু করুন।
- **প্রত্যাশা:** Setup Wizard (৫ ধাপ) আসে: ব্যবসা → ওপেনিং ব্যালেন্স → ইনভয়েস → অ্যাডমিন → সারসংক্ষেপ। কোথাও “Coming Soon”/lorem/ইংরেজি বানান ভুল নেই; বাংলা লেখা পরিষ্কার।
- **যাচাই:** উইন্ডোর কোনো লেখা কাটা/overlapping নেই।

### 3) ব্যবসা সেটআপ
- ব্যবসার নাম: `আপনার দোকানের বাংলা নাম` (যেমন `মেসার্স আলম স্টোর`), ফোন, ঠিকানা দিন। ওপেনিং Cash ৳50,000 রাখুন। ইনভয়েস Prefix `MERQO` রাখুন। Admin ইউজার `owner` / পাসওয়ার্ড `Passw0rd!` তৈরি করুন।
- **প্রত্যাশা:** Dashboard এ ব্যবসার বাংলা নাম দেখায়।

### 4) পণ্য তৈরি (Product)
- Products → নতুন পণ্য: `চাল (মিনিকেট)`; ক্রয় মূল্য ৳৫০.০০, বিক্রয় ৳৭০.০০, ওপেনিং স্টক ৫ কেজি, বারকোড `1234567890128` (নিজের বারকোড ব্যবহার করলে আরও ভালো)।
- **প্রত্যাশা:** টেবিলে বাংলা নাম ঠিক, SKU/বারকোড দেখায়, ১১ ধরনের পণ্য পেজিনেশন ঠিক।

### 5) ক্রয় (Purchase)
- Purchases → নতুন ক্রয়: সাপ্লায়ার `রহিম ট্রেডার্স` (নতুন) → পণ্য ১০ কেজি @ ৳৫০ → মোট ৳৫০,০০০ → Cash থেকে ৳৩০,০০০ পেমেন্ট।
- **প্রত্যাশা:** Due ৳২০,০০০, স্টক ১৫ কেজি। সাপ্লায়ার খাতায় বাকি ৳২০,০০০।

### 6) বারকোড দিয়ে বিক্রি (POS)
- POS → **USB স্ক্যানারের যাচাই (মানব-হার্ডওয়্যার):** স্ক্যানার দিয়ে `1234567890128` স্ক্যান করুন। **বাস্তব স্ক্যানার** দিয়ে কার্টে লাইন যোগ হয় কি? না হলে ম্যানুয়ালি পণ্য খুঁজে কার্টে ৩ কেজি যোগ করুন, বিক্রয় মূল্য ৳৭০, Cash ৳১০,০০০ পেমেন্ট → ইনভয়েস তৈরি।
- **প্রত্যাশা:** মোট ৳২১,০০০, Due ৳১১,০০০, স্টক ১২ কেজি। কীবোর্ড-ফার্স্ট POS (Tab/Enter) কাজ করে।

### 7) গ্রাহকের বাকি
- Customers → `করিম মিয়া` → বাকি ৳১১,০০০ দেখায় কি? Ledger এ ডেবিট/ক্রেডিট ব্যালেন্স মিলে কি?

### 8) গ্রাহক পেমেন্ট
- Customers → Receive Payment → Cash থেকে ৳৪,০০০ ও পরে বাকি ৳৭,০০০ রিফান্ড/পেমেন্ট করে বাকি ৳০ করুন।
- **প্রত্যাশা:** Running-balance ঠিক।

### 9) সাপ্লায়ার পেমেন্ট
- Suppliers → `রহিম ট্রেডার্স` → Pay Supplier → Cash থেকে ৳১০,০০০।
- **প্রত্যাশা:** বাকি আপডেট।

### 10) খরচ (Expense)
- Accounts → Expense → ক্যাটাগরি (যেমন `যাতায়াত ভাড়া`) → ৳৫,০০০ Cash থেকে।

### 11) অ্যাকাউন্ট ট্রান্সফার
- Accounts → Transfer → Cash থেকে Bank এ ৳১০,০০০।

### 12) MFS লেজার
- Agent (বিকাশ/নগদ) → CASH_IN ৳২০,০০০, চার্জ ৳৪০০, কমিশন ৳১০০।

### 13) বিক্রয় ফেরত (Sales Return)
- Sales → আগের বিক্রয়ের Detail → Return → ১ কেজি ফেরত → Cash থেকে ৳৭,০০০ রিফান্ড।

### 14) ক্রয় ফেরত (Purchase Return)
- Purchases → আগের ক্রয়ের Detail → Return → ২ কেজি ফেরত।

### 15) চালান (Invoice) — বাংলা যাচাই
- Invoices → আগের বিক্রয়ের চালান Preview → ভাষা বাংলা ঠিক কি? পণ্য `চাল (মিনিকেট)`, দাম, ছাড়/ট্যাক্স (যদি থাকে) ঠিক?

### 16) PDF
- Invoice → PDF Export (A4) → ফাইল খুলুন।
- **প্রত্যাশা:** বাংলা ফন্ট (Noto Sans Bengali) পরিষ্কার, চালান নম্বর/তারিখ/পরিমাণ/মোট/paid/due/footer/logo ঠিক। PDF >5 KB (গেটে 34,546 bytes ছিল)।

### 17) প্রিন্টার (মানব-হার্ডওয়্যার)
- POS/Invoice → Print:
  - 58mm থার্মাল (যদি থাকে) — কাটিং, বাংলা, QR ঠিক?
  - 80mm থার্মাল — একই।
  - A4 — ফুটার/লোগো।
- **নোট:** “প্রিন্টার সাপোর্ট আছে” ≠ “আপনার প্রিন্টারে পরীক্ষা হয়েছে” — আলাদা লিখুন।

### 18) ব্যাকআপ
- Settings → Backup → Create Backup → ফাইল তৈরি হয়? `backups/merqo-backup-*.db` 300+ KB?
- **যাচাই:** `backups` ফোল্ডারে ফাইল, `integrity ok`.

### 19) রিস্টোর
- একটি নতুন পণ্য বানিয়ে ব্যাকআপ নিন → আরেকটি পণ্য বানান → Restore → নতুনতম ব্যাকআপ → রিস্টার্ট → আগের “নতুন পণ্য” আর নেই, কিন্তু আগেরটি আছে? Safety backup `merqo-pre-restore-*.db` তৈরি হয়েছে কি?
- **সতর্কতা:** রিস্টোরের আগে সাবধান — আসল ডেটা সেফটি ব্যাকআপে যায়।

### 20) ডিসপ্লে স্কেলিং (মানব-যাচাই)
- Windows Settings → Scale 100% → অ্যাপ চালু → Dashboard/POS/Products/Reports/Settings ঘুরে দেখুন — কোথাও লেখা কাটা/চাপা/আইকন বাইরে যায়নি তো?
- 125%, 150%, 175% এ একই।

### 21) স্ক্যানার — Bluetooth (মানব-হার্ডওয়্যার)
- Bluetooth স্ক্যানার পেয়ার করে POS-এ স্ক্যান করুন — USB-এর মতো কাজ করে কি? ডিসকানেক্ট/রিকানেক্টে সমস্যা?
